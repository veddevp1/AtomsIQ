# VED Weather

A responsive weather dashboard for desktop and mobile, with live current conditions, hourly forecasts, and a 7-day outlook.

## Features
- Search weather by city
- Use device location (with browser permission)
- Current temperature and feels-like temperature
- Humidity, wind speed, UV index, and cloud cover
- Hourly and 7-day forecasts
- Sunrise and sunset times
- Responsive dark interface

## Project files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — weather API, city search, and UI updates

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Keep an internet connection enabled for live weather data and city search.

For best results, use a local development server such as the Live Server extension in VS Code.

## Data source
Weather and geocoding data are provided by [Open-Meteo](https://open-meteo.com/). No API key is required.
